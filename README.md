# Power BI Project: Sales and Product Visualization

## Project Overview
This Power BI project focuses on visualizing sales and product performance data. The report includes key metrics, trends, and insights to help in decision-making.

## Features
- Interactive sales dashboards
- Product-wise performance analysis
- Key performance indicators (KPIs)
- Trend analysis using Power BI visuals

## File Information
- **visual on sales and product.pbix** → Power BI report file containing data and visualizations.

## How to Use
1. Download the `.pbix` file from this repository.
2. Open it using **Power BI Desktop**.
3. Explore the visualizations and insights.

## Requirements
- Microsoft Power BI Desktop (latest version)
- A basic understanding of Power BI for customization
